The problem

Assessment Challenges

  • Free-format answers are time-consuming to mark
  • Large classes make marking difficult to scale
  • Handwritten responses raise legibility issues
  • Fewer questions lead to limited topic coverage
The challenge is not simply marking faster. It is designing assessments that scale without sacrificing quality.
One possible approach

Advantages of Multiple-Choice Exams

Efficiency

  • Quick and efficient marking
  • Scales well to large classes
  • Allows many questions per exam

Assessment Quality

  • Broader topic coverage
  • More consistent marking
  • Improved reliability and fairness
Multiple-choice does not have to mean low-level assessment.
The core idea

Question Generators

A question generator is an abstract template from which questions are produced algorithmically.

How?

  • Questions are algorithmically specified
  • Defined using a programming language
  • Generated automatically

Programming is only getting easier…

  • AI tools can help write the generators
  • We can actually author generators without a single line of code
The key property

Different Questions.
Same Learning Outcome.

Student A

Receives one instantiation of the question.

Different numbers Different text data Different surface details
Same difficulty Same concept Same learning outcome

Student B

Receives another instantiation of the same underlying question.

Different numbers Different text data Different surface details
Same difficulty Same concept Same learning outcome
The questions are isomorphic: systematically different, but equivalent by design.

A common misconception

Question Generators
vs Question Banks

Traditional Question Bank

  • Static questions
  • Typically generated manually
  • Finite collection
  • Equivalence must be curated

Question Generator

  • Dynamic questions
  • Generated automatically
  • Effectively unlimited variants
  • Isomorphism enforced by design
Why it matters

Benefits of Isomorphic
Question Generation

  • Effectively unlimited question variants
  • Generate practice questions easily
  • Reuse questions without losing assessment integrity
  • Students need not see the same instantiation
  • Repeat entire exams safely
Isomorphism is systematic and guaranteed by the generator , rather than relying on manual curation.
A less obvious benefit

Operational Advantages

Exam Logistics

  • Easy arrangement of special exams
  • Different versions can be generated automatically
  • Students can be seated closer together

At Scale

  • Reduced space requirements
  • Lower supervision overhead
  • Particularly useful for large classes
  • Useful for centrally scheduled examinations as well as mid-semester tests
Operational advantages matter greatly at scale.
Key Operational Advantage

Reduced Space Requirements

Students can sit closer together because each student receives a different but equivalent question.

Less separation between students can mean less examination space required.
Especially useful for large classes. Individualised questions can make in-class tests practical while maintaining academic integrity.
The important distinction

Question Format ≠ Question Quality

Multiple-choice can test…

  • Understanding
  • Analysis
  • Application
  • Evaluation
  • Problem solving

But we want to avoid by design…

  • Pure recall
  • Rote memorisation
  • Mechanical formula substitution
  • Questions with obvious distractors
The quality of the assessment depends on the thinking the question requires, not whether the answer is selected from a list.
The instructor perspective

Good Questions Are Hard

  • Designing good questions takes time and effort
  • Good assessment requires higher-order thinking by instructors

Question generator design amplifies instructor effort — but once designed, a generator can be reused almost indefinitely.

BUT ... AI tools can help with some of the heavy lifting.

Question design

Designing Higher-Order MCQs

1
Scenario Present a realistic situation or problem
2
Reflective Question Ask students to reason about the implications
3
Implications Identify true and false implications
4
MCQ Choose answer options from the implication pools

True implications

A pool of true statements that can form correct answers.

False implications

A pool of plausible but false statements that can form distractors.

Result: a question that targets higher-order thinking in Bloom’s taxonomy — rather than simple recall.
A higher-order example

Generated Questions

Simplified TLS

TLS normally establishes separate encryption and MAC keys for the two communication directions.

Suppose a simplified TLS establishes a single encryption key and a single MAC key for both directions.

What vulnerability does this simplified TLS create?

X. An intermediary can potentially re-send a client-to-server message to a client posed as a server-originated message.

Y. An intermediary can potentially mount a reflection attack.

Z. An intermediary can potentially re-send a server-to-client message to a server posed as a client-originated message.

A) X and Y only
B) X and Z only
C) Y and Z only
D) All of X, Y and Z
E) None, or only one of X, Y and Z

Simplified TLS

TLS normally establishes separate encryption and MAC keys for the two communication directions.

Suppose a simplified TLS establishes a single encryption key and a single MAC key for both directions.

What vulnerability does this simplified TLS create?

X. An intermediary can potentially mount a reflection attack.

Y. A client may pose as the server given that the client knows the server keys.

Z. An intermediary can decipher messages the client sends to the server.
 

A) X only
B) Y only
C) Z only
D) None of X, Y, and Z
E) All, or two of X, Y, and Z
The generator randomly selects from true and false implications to create different question variants.

The long-term view

Question Generators:
Long-Term Payoff

Short Term

  • Higher initial investment
  • More design effort
  • More validation required

Long Term

  • Reuse across semesters
  • Unlimited practice material
  • Multiple examination versions
  • Reduced maintenance of question banks
  • Scalable assessment
  • Auto-grading
  • Highly reduced physical space requirements for the examination
Initial cost → reusable assessment infrastructure and operational efficiency.
