The problem predates generative AI

False claims can enter
the scholarly record.

01

Fabricated evidence

Data or samples can be invented, substituted or manipulated.

02

SCIgen

Plausible-looking scientific papers can be generated without meaningful science underneath.

03

Misleading citations

References can be real but inaccurate, distorted or used to support claims they do not support.

AI did not invent unreliable scholarship. It changes the speed and cost at which plausible-looking claims can be produced.

A useful distinction
True The available evidence supports the claim.
False The available evidence contradicts the claim.
Unverifiable The available evidence is insufficient to establish whether the claim is true or false.
“We tend to think about integrity as distinguishing true from false. But there is a third category.”

The problem is bigger than whether a paper exists.

We started by asking a very simple question: does this reference actually exist? But that's only one layer of trust in the scholarly record. A paper and its references can exist, — BUT we can still be repeating a claim that nobody has actually checked.
